Section 3

Build it on the bar

Pass / fail

The certifying manager picks three drinks at random and watches the full build. Start the clock when the ticket is called and stop it when the drink hits the rail — the standard is 2:00, garnish included. Every line has to be checked for the build to count. One missed line is a failed build.
