# Game Day Menu Checklist — TownHall

**Audience:** Managers on duty · **Owner:** MOD who opens the game day
**Rule:** Every line gets initialed and timed. If a line is not done, it is not checked.

Menus are the first thing a guest touches. A wrong price, an old beer, or a stack of last week's paper is the guest's first impression of how we run the building. Get this done the day before, not an hour before doors.

---

## Day Before — 100% of it, before you leave

### 1. $1 Up menus printed
- [ ] Confirm the current $1 Up file is the current one — check the date on the file before you print. Print nothing you did not open and read.
- [ ] Proof one copy first: pricing, spelling, dates, and the game day it applies to.
- [ ] Print full count for the floor: **tables, bar, host stand, patio, private/reserved tops.**
- [ ] Print the back-of-house copies: **kitchen line, expo, service bar.** If the staff can't see it, they can't sell it.
- [ ] Pull and throw away every old version in the building. Old menus in a stack is how a guest gets quoted a price we don't honor.

### 2. Beer list menus updated for game day
- [ ] Walk the coolers and the draft wall yourself. Count it. Do not update a beer list off of last week's list.
- [ ] 86 anything we can't pour all day. If it's going to blow by kickoff, it does not go on the game day list.
- [ ] Confirm every price on the list matches the POS. The menu and the POS say the same number or we fix it now.
- [ ] Add the game day features and any drink specials tied to the game.
- [ ] Reprint, replace at every table and every bar rail, and hand the new list to the bar team before they set up.

### 3. Bottle Service menus updated
- [ ] Verify every bottle on the list is physically in the building and in count. We do not sell what we cannot pour.
- [ ] Confirm bottle pricing, package pricing, and what each package includes — mixers, setups, minimums.
- [ ] Update reserved/VIP inventory for the game: what is held, what is sellable, who owns each table.
- [ ] Reprint and get the updated list to the host stand, the bar, and anyone selling tables. If the person selling it is holding an old sheet, it's our mistake, not theirs.

### 4. Game Day menus for brunch
- [ ] Confirm which game day brunch items are running and that the kitchen has the product to run them all day.
- [ ] Confirm brunch start and end times on the menu match what we are actually serving.
- [ ] Confirm brunch drink features and pricing against the POS.
- [ ] Print and set brunch menus at every table before you close. Morning does not have time to do this.

---

## Game Day — Before doors

- [ ] Walk the floor and touch every table. Right menu, current version, clean, no bent or stained copies.
- [ ] Every station holds a backup stack: host stand, bar, server alley.
- [ ] Every old version is out of the building — not in a drawer, out.
- [ ] **Pre-shift covers the menus.** Prices, features, what's 86'd, what we are pushing. Your staff cannot sell what you did not tell them.
